O que é Lógica Booleana?

Lógica Booleana é a base de todos os computadores. Opera apenas com dois valores: 0 (falso/desligado) e 1 (verdadeiro/ligado). Toda computação moderna é construída sobre esses dois estados.

🔮

O que são Portas Lógicas?

Portas lógicas são circuitos eletrônicos que recebem sinais de entrada (0 ou 1) e produzem uma saída baseada em regras matemáticas. São os blocos fundamentais de processadores, memórias e todos os chips digitais.

🛠️

Como usar o LogicLab

Clique nos botões A e B de cada porta para alternar entre 0 e 1. A saída atualiza em tempo real. Use o Modo Construtor para conectar portas entre si e criar circuitos complexos!
