Listas ordenadas

listas ordenadas são usadas em momentos como por exemplo em receitas de bolo, onde precisa de uma ordem correta.

com o uso da tag <ol> para delimitar a lista e <li> para definir os itens dela. Exemplo:

  1. item 1
  2. item 2
  3. Item 3
  1. item 1
  2. item 2
  3. Item 3
  1. item 1
  2. item 2
  3. Item 3
  1. item 1
  2. item 2
  3. Item 3
  1. item 1
  2. item 2
  3. Item 3

Percebe que <ol> é uma tag tipada podendo usar o parâmetro Start para tal ato.
