Folha de estilo CSS

Trata-se de um padrão de formatação para páginas web, que vai além das limitações impostas pelo HTML. Proposto pela W3C, o CSS foi introduzido pela primeira vez na Microsoft, no lançamento do Browser Internet Explorer 3.0
